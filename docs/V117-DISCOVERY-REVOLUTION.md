# TRUST V117 — Discovery Revolution

V117 changes the acquisition proposition from **more products** to **better decisions**.

## Consumer surface
- Shopping Mission: query + budget + deadline + priority.
- Reasoned Ranking: every recommendation exposes concise reasons.
- Smart Bundles: complementary products without hidden commission logic.
- Compare Anywhere: foundation for shareable comparisons up to four products.
- Visual Search Boundary: upload UX and provider boundary without fabricated matches.
- Deal Intelligence: price-watch and transparent discount positioning.
- Personal Feed: consent-first personalization.

## Admin surface
`/discovery/admin` is private and server-gated. It provides governance-oriented discovery metrics and rules.

## Production boundaries
- The discovery engine is deterministic decision-support scaffolding, not a trained model.
- Real visual similarity requires a configured Vision Provider.
- Persistent behavioral analytics require the V117 migration and retention policy.
- Any sponsored ranking must remain explicitly disclosed and governed.

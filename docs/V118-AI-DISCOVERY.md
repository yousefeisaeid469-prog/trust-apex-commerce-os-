# V118 AI Discovery Architecture

TRUST's discovery layer is designed as a decision system, not a black-box product carousel.

1. Shopping Mission captures intent.
2. Concierge interprets intent and asks for missing constraints.
3. Candidate retrieval must come from the live catalog provider.
4. Ranking emits reasons, confidence, and policy metadata.
5. Visual Search uses a provider-neutral interface for image embeddings/similarity.
6. Discovery events are consent-aware and retention-controlled.
7. Private admin receives governance telemetry without exposing admin controls to customers.

# Merchant OS 2.0 — V193

V193 consolidates the merchant surface around a command-center model. It derives operational health, priorities, revenue, AOV, catalog size, stock units, and order-flow views from the existing authenticated merchant APIs.

The health score is an explicit deterministic projection of catalog availability and delivered-order ratio. It is not a machine-learning claim. The UI avoids displaying unsupported profit, payout, campaign, or provider metrics.

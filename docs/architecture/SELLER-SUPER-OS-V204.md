# TRUST V204 — Seller Super OS 3.0

V204 consolidates the seller journey into one operational decision surface. It does not clone proprietary marketplace internals; it turns public marketplace patterns into provider-neutral, explainable capabilities over TRUST's existing merchant APIs.

## Surfaces
- Catalog quality: title/category/tags/image/price completeness.
- Inventory: stockout and low-stock urgency.
- Orders: processing and shipped operational attention.
- Trust: verification state.
- Growth: targeted experiments, deals/coupons/ads as policy-gated opportunities.
- Fulfillment and finance: surfaced as existing systems; no fabricated provider success or profit numbers.

## Safety and integrity
- Recommendations are deterministic and evidence-bearing.
- Listing prompts explicitly forbid invented product specifications.
- Financial actions are not executed by the recommendation layer.
- External services remain adapters with explicit provider readiness.

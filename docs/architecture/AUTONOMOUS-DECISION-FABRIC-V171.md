# TRUST V171 — Autonomous Decision Fabric

V171 adds a governed decision/action layer above Network Intelligence. Signals become policy-bounded proposals, proposals become deterministic plans, plans can be simulated, and only explicitly permitted AUTO_EXECUTE actions can execute. Approval-required actions remain pending.

Safety properties: tenant isolation, risk/confidence/budget ceilings, deterministic ordering, idempotency, and non-mutating simulation.

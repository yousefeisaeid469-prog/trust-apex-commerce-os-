# TRUST V312.0.0 — Master Release

## Global Logistics Adaptive Learning

V312 adds a durable learning layer over V307 reconciled shipment outcomes and feeds confidence-weighted carrier/service performance into the V311 network optimizer.

### Delivered

- Adaptive carrier/service profiles with confidence shrinkage.
- Durable learning runs and observations.
- Historical outcome collection from reconciled tracking events.
- Adaptive network optimization preview.
- Multi-currency TRUST-E2E service descriptors while preserving the original default service codes.
- Learning and adaptive-optimization APIs.
- Deterministic regression tests and audit evidence.

### Validation boundary

The release was syntax-checked and tested with Node's experimental TypeScript stripping path. Full `tsc`, live PostgreSQL, and live DHL/FedEx/UPS connectivity are not certified in the current environment.

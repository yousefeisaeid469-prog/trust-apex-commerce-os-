# TRUST V117 — Discovery Revolution

TRUST now competes on **decision quality, transparency, and shopping convenience** rather than raw catalog size.

### Added
- Shopping Mission engine
- Reasoned product ranking
- Smart bundle engine
- Discovery API
- Visual-search provider boundary API
- Customer Discovery Revolution page
- Private Discovery Intelligence admin page
- Durable discovery sessions, feedback, and experiments schema

### Release principle
The goal is to make leaving another marketplace feel rational: TRUST should understand the mission, explain the recommendation, reduce comparison effort, and preserve confidence before and after checkout.

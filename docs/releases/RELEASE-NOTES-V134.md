# TRUST V134 — Acquisition-Ready Integrity

V134 is a hardening release focused on financial correctness, failure behavior, operational evidence and acquisition diligence.

### Highlights
- Request-bound idempotency fingerprints.
- Refund settlement separated from refund request.
- Provider-confirmed refund state transitions.
- Inventory reservation release on pre-fulfillment payment failure.
- Deterministic financial failure harness.
- Release evidence and incident-event persistence primitives.
- Acquisition readiness, maturity, security, SLO/DR, IP and data-room documentation.

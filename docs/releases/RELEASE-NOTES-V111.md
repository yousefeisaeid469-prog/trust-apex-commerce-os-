# TRUST V111 — MERCHANT SUPER OS

V111 adds a dedicated merchant command experience over the existing merchant APIs.

## Included
- Merchant Super OS route: `/merchant-super-os`
- Unified merchant overview, catalog, orders, growth, finance and store/security tabs
- Mobile-first responsive layout with touch-friendly controls
- Merchant growth planning and AI Copilot experience layer
- Finance guardrails that avoid presenting mock margin/payout data as production truth
- Existing server-side merchant APIs remain the source of protected operational data
- Package version bumped to 111.0.0

## Important
Growth recommendations are experience-layer suggestions. Financial settlement, payment provider data, and true margin calculations require production integrations and cost data.

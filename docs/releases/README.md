# TRUST release history

Release notes are stored here so the repository root stays focused on runtime entry points and current project documentation.

- `V001.md` … `V228.md`: historical release records.
- `MASTER-RELEASE.md` remains at the repository root as the current release index when present.
- Release tooling should reference this directory rather than placing historical records in the root.

Historical release notes are evidence of prior work; they are not, by themselves, proof that a capability is live in production.

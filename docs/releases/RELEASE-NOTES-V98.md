# TRUST V98 — APEX ECOSYSTEM EXPERIENCE

V98 is an experience and platform-hardening release built on V97.

## Experience
- Unified global command palette (Ctrl/⌘ K).
- Skip-navigation accessibility affordance.
- Online/offline status indicator.
- Improved focus-visible treatment.
- Reduced-motion support.
- Mobile touch-surface improvements and safe-area handling.
- PWA manifest for a cleaner installable mobile experience.

## Platform hygiene
- Runtime version is now V98.0.0.
- Legacy version labels in the primary marketplace shell are updated.
- Admin remains server-gated through the existing private control-plane boundary.

## Validation note
Static release checks can validate structure and contracts, but a real production deployment still requires dependency installation, a successful Next.js build, real infrastructure credentials, and staging smoke tests.

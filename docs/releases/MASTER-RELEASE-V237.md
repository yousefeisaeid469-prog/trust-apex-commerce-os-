# TRUST V237.0.0 — Merchant Commerce Control Plane

V237 extends the V236 customer commerce/data platform with a durable merchant operating system and control plane. It adds merchant-scoped persistence and execution primitives across catalog, inventory, pricing, promotions, payouts, tax, staff access, procurement, sales channels, billing, risk, compliance, support, automation, forecasting, reconciliation, alerts, snapshots, and operator decisions.

Verification is source-level in this environment. Full Next.js build/typecheck remains dependent on installing the project's dependency tree; no build pass is claimed without those dependencies.

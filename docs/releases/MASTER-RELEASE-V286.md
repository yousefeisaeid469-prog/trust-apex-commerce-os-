# TRUST V286.0.0 — Financial Control Hardening

- Multi-seller disputes allocate chargeback exposure from actual seller credits.
- Dispute allocations are unique per seller and total is durably recorded.
- Provider payout reconciliation rejects duplicate provider events.
- Dispute resolution and payout reconciliation emit durable outbox events.
- Existing V282–V285 settlement, delivery release, payout, refund and statement flows remain the financial backbone.

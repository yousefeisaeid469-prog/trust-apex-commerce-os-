# TRUST V134 — Buyer Data Room Index

## Technical
- Architecture overview
- Product maturity matrix
- Security threat model
- SLO / DR plan
- Release checklists and release evidence
- Migration manifest
- Test results
- Deployment instructions

## Commercial
- Revenue and ARR history
- GMV / order volume
- Active merchants and customers
- Retention / cohort data
- Gross margin and cloud spend
- Sales pipeline

## Legal
- Corporate ownership
- IP assignments
- Trademarks/domains
- Customer/vendor contracts
- Privacy terms
- Open-source license report

## Diligence rule
No metric is considered buyer-grade evidence until it is sourced, dated, reproducible and tied to a system of record.

# TRUST V134 — IP & License Inventory

## Ownership checklist
- Confirm every source file is authored by, assigned to, or licensed to the selling entity.
- Record contractor/employee invention assignments.
- Record trademarks and domain ownership.
- Record product/design/content ownership.
- Record AI-generated asset provenance where relevant.

## Third-party dependency checklist
- `next`
- `react`
- `react-dom`
- `pg`
- TypeScript and Node type packages

The exact license text and transitive dependency inventory should be generated from the installed lockfile in a connected build environment before diligence. Do not represent this repository as having a completed legal license audit until that evidence exists.

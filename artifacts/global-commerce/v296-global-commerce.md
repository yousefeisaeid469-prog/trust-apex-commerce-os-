# V296 Global Commerce Evidence

V296 adds a provider-neutral global commerce foundation rather than claiming global production certification.

## Implemented
- country policy registry
- supported settlement currencies
- integer minor-unit money arithmetic
- explicit FX quote validation and expiry
- country tax boundary
- shipping-mode/provider abstraction
- country/payment-method boundary
- durable quote-evidence schema

## Not claimed
- live tax/legal compliance in every jurisdiction
- live FX provider certification
- live carrier certification
- live payment-provider certification
- production global rollout

Those claims require real providers, credentials, environments, and jurisdiction-specific validation.

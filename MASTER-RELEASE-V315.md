# TRUST V315 — Verification Platform

V315.0.0 adds an executable verification and integration foundation around critical commerce workflows.

- Payment and carrier deterministic sandbox adapters.
- Failure injection and deterministic event replay.
- Load/performance gates.
- PostgreSQL integration harness and rollback verification.
- Durable verification run/result/evidence schema.
- Verification catalog API.
- Explicit live-only skip semantics; no live external provider claims.

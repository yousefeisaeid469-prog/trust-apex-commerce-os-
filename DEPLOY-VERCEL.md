# TRUST V64 APEX ULTRA — Vercel Deployment

1. Create a new GitHub repository.
2. Upload the **contents of this folder** so `package.json`, `app/`, `components/`, `data/`, and `lib/` are at the repository root.
3. Import the repository into Vercel.
4. Framework: Next.js (auto-detected).
5. Build command: `next build`.
6. Install command: `npm install`.
7. Do not upload `node_modules` or `.next`.
8. Deploy.

A prebuild structural check runs before `next build` and stops the deployment if required files or relative imports are broken.

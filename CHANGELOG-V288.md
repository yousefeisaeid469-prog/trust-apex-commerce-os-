# TRUST V288.0.0 — Fulfillment Network Runtime

- Added durable FBA-like fulfillment orders bound to marketplace order shipments.
- Added warehouse custody records and immutable fulfillment status events.
- Added shipment binding and delivery gating so fulfillment cannot be marked delivered before the real shipment is delivered.
- Added durable inbound inventory movement records with idempotency and on-hand/inbound inventory counters.
- Added authenticated merchant-facing fulfillment network API.
